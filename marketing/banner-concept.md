# Social launch banner — design concept

Written specifications for a designer (or you, in Figma) to produce the actual images. No PNG is generated by this template.

## Targets

| Platform        | Dimensions | File                 |
| --------------- | ---------- | -------------------- |
| LinkedIn share  | 1200 × 627 | `linkedin-og.png`    |
| LinkedIn header | 1584 × 396 | `linkedin-cover.png` |
| X share / OG    | 1600 × 900 | `x-og.png`           |
| GitHub social   | 1280 × 640 | `github-social.png`  |

Same visual system, three crops.

## Vibe

Modern developer aesthetic. Dark theme. Clean gradients. Minimal copy. Code feel without being clichéd terminal screenshots. Think Vercel landing, Linear changelog, Resend docs.

## Color system

Primary palette pulled from the template's OKLCH dark tokens:

- **Background**: `#0A0A0A` (very near-black, OKLCH 0.145)
- **Foreground**: `#FAFAFA` (near-white, OKLCH 0.985)
- **Accent gradient**: linear from `#A78BFA` (violet 400) to `#22D3EE` (cyan 400), 135° angle. Optional secondary: `#F472B6` (pink 400) for thread cards.
- **Muted text**: `#A1A1AA` (zinc 400)
- **Border / divider**: `#27272A` (zinc 800)

Keep saturation low except for the gradient mark.

## Typography

- **Headline**: Geist Sans, weight 600, tight letter-spacing (-0.02em). Size scales: 96px (1600px wide), 84px (1200px wide), 56px (LinkedIn cover crop).
- **Sub**: Geist Sans, weight 400, color `#A1A1AA`. 28–32px.
- **CLI tag**: Geist Mono, weight 500, 24–28px, on a 1px-bordered chip with rounded corners (`#27272A` border, `#0F0F12` fill).

```
│                                                            │
│                                                            │

```

- Logo mark top-left, 32px square, the same gradient blob as in `AppHeader.tsx`.
- Headline left-aligned, 80–96px, two lines.
- Sub headline below, 28px, muted.
- CLI chip centered under the sub, max-width 360px.
- Soft gradient orb (radial, 600×600, low opacity) in the top-right corner, blurred 80px. Adds depth without distraction.
- 96px padding all around.

## What to avoid

- Stock developer photos.
- Generic blue gradient hero.
- The Next.js triangle logo (template is independent).
- Glassmorphism without purpose.
- More than five distinct UI elements per banner. Keep it scannable in a feed.

## Export checklist

- PNG, 2x resolution variants for retina.
- Compress with tinypng or squoosh before uploading.
- Verify legibility at 50% zoom (LinkedIn feed scale).
- Test on both LinkedIn dark and light theme — the very dark background works on both.

## File destination

Once produced, place under `public/og/` and update `siteConfig.ogImage` in `src/global/config/site.ts` if you want the same image used for the live site's Open Graph card.
